# CRMIP Model

Capacitance-Resistance Model for Injector-Producer pairs (CRMIP).  
This tool estimates time-varying connectivity and time constants between injectors and producers from historical injection and production data.

## Features

- Dynamic (time-stepping) CRMIP fitting
- Optional single aquifer support
- Distance-based or user-defined connectivity constraints
- Gentil water-cut model for oil rate estimation
- Side-by-side comparison: with vs without aquifer
- Connectivity maps, heatmaps, and time-series plots
- Export of parameters to Excel
